# Scenario: sparse-static

**Class:** sparse / static

[← Benchmark index](../../benchmarks.md) · [Metrics](../metrics.md) · [Methodology](../methodology.md)

## What it stresses

Connectivity-limited but stable (pause=900). The paper base field with mobility
switched off, so route churn is removed and what remains is pure reachability —
the low-mobility end of the Broch pause sweep.

## Configuration

| nodes | area long edge (m) | max speed (m/s) | pause (s) | flows | propagation |
|---|---|---|---|---|---|
| 50 | 1500 | 20 | 900 | 20 | range |

Defined as `DISCRETE["sparse-static"]` in
[`ns3/tools/run-scenarios.py`](../../../ns3/tools/run-scenarios.py)
(`scenario=paper pause=900`). The per-merge `benchmarks` workflow runs the
taxonomy with `--quick`.
