How AntHocNet finds a route

Six phones in a row, one call from phone 0 to phone 5 — frames from the learn site, where the real routing core runs as WebAssembly.
1
Ants searchPhone 0 has no route, so it sends reactive forward ants. Each phone re-broadcasts them (orange rings) until one reaches phone 5.
2
Ants lay pheromoneThe ant that arrived turns into a backward ant and walks home, leaving pheromone on every hop (the blue trail).
3
Packets follow the scentData packets (purple crates) pick each next hop by pheromone; the strongest trail almost always wins. Delivered ✓.

One protocol, every network type

The same core, unchanged defaults, in each world of the learn site. Each one has a measured results page in ns-3.
Ad hoc (MANET)Phones: some walk, some stand still. The bold trail is each call's strongest route.
Static Wi-Fi meshRouters on poles. Nothing moves, so the routes are found once.
Vehicles (VANET)Cars on a street grid; buildings block the radio at every corner.
Drones (FANET)A 3-D swarm at about 20 m/s; links last seconds.
SatellitesA Walker constellation: 8 orbital planes; links stay, their delay changes.
