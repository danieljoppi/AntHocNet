    Bring your own protocol: the comparison harness

    Every Lab number comes from one ns-3 program that runs several routing protocols on the same seeds, so each difference carries a confidence interval. You can run it on your own protocol: an ns-3 routing module, or a per-hop arm on the adaptive base in about 270 lines.

    ./ns3 run "anthocnet-compare --scenario=paper --runs=10 --protocols=anthocnet,aodv,olsr --diag"

    Coming in v2.6.0: the harness becomes routing-bench, a module that names no protocol. Your arm registers itself; anthocnet-compare keeps working.
